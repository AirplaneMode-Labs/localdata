localdata demo

Everything runs in this tab. Nothing is uploaded; the only network requests are for this page's own files.

Built from main at local by .github/workflows/pages.yml

Browser requirements

  • ? OPFS (navigator.storage.getDirectory, Chrome/Edge 86+, secure context)
  • ? IndexedDB
  • ? navigator.storage.estimate()
  • ? navigator.storage.persist()

All Airplane Mode Labs demos share one browser origin (airplanemode-labs.github.io): storage, quota, estimate() and persist() are shared between them. This demo writes only under airplanemode-localdata (namespace demo-fill for the quota fill).

What this demo does not do yet

  • query() rejects with StorageError code not_implemented; the vector index lands in Sprint 4 (design note: docs/vector-index.md).
  • There is no vector index and no similarity search of any kind (Sprint 4).
  • No cross-tab coordination: two tabs writing the same namespace can leave the accounting record stale until the next read repairs it.
  • Chrome under-reports IndexedDB usage in estimate(), so the browser figure and the SDK figure will not match on the indexeddb driver.
  • persist() may be refused without user engagement with the site; a refusal is shown as false, not as an error.
  • No service worker: offline after the first load is best effort (Chrome's HTTP cache), not guaranteed.
